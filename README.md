# Restaurant Order & Kitchen Manager

A web-based restaurant order and kitchen management system designed to help restaurants manage customer orders and kitchen workflows.

## Problem

Small restaurants and takeaway businesses can struggle with tracking orders, communicating order status between the front counter and kitchen, and keeping accurate records of completed orders.

## Goal

Build a simple system that allows restaurant staff to:

* Create customer orders
* View incoming orders
* Send orders to the kitchen
* Update preparation status
* Mark orders as ready
* Complete orders
* Track basic sales information

## Core Order Workflow

```text
Received → Preparing → Ready → Completed
```

## Planned Technology

* Python
* Flask
* HTML
* CSS
* JavaScript
* SQLite

## Current Status

🚧 Day 1 — Project setup

## Future Improvements

Possible future features include:

* User accounts and staff roles
* Kitchen display mode
* Sales reports
* Inventory management
* Receipt generation
* Online ordering
* Payment integration
